# 🎮 LEVEL UP

> Transforme suas tarefas em missões. Conquiste objetivos, acumule XP e evolua de nível!

**LEVEL UP** é um painel de produtividade gamificado desenvolvido para transformar a organização de tarefas em uma experiência inspirada no universo dos games.

O projeto utiliza uma interface futurista com estética cyberpunk, permitindo que os usuários acompanhem seu progresso, concluam missões e visualizem sua evolução.

---

## 🕹️ Sobre o projeto

A proposta do LEVEL UP é tornar a produtividade mais divertida por meio de elementos de gamificação.

Em vez de simplesmente organizar tarefas, o usuário passa a ter objetivos, recompensas e níveis para alcançar.

O projeto também faz parte de um desafio prático de desenvolvimento Front-end, com foco na aplicação dos conhecimentos de HTML, CSS e JavaScript.

## ✨ Funcionalidades

- [ ] Dashboard com informações do jogador.
- [ ] Sistema de cadastro de missões.
- [ ] Conclusão e exclusão de tarefas.
- [ ] Sistema de experiência (XP).
- [ ] Progressão de níveis.
- [ ] Sistema de conquistas.
- [ ] Armazenamento de dados com LocalStorage.
- [ ] Interface responsiva.

## 🚀 Como executar

1. Clone este repositório:

```bash
git clone https://github.com/LiedsonF/LevelUP.git
```

2. Entre na pasta:

```bash
cd LevelUP
```

3. Abra o arquivo `index.html` no navegador.
